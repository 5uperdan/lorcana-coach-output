# Lorcana Coach: published reviews

Game reviews written by Lorcana Coach, a private coaching project, and published with GitHub Pages at
https://5uperdan.github.io/lorcana-coach-output/.

- `reviews/`: one review per game, with screenshots of the board at each decision in `reviews/screenshots/`.
- `index.md`: the site's front page, which lists the reviews automatically.

Links into the coach's knowledge base point to the private project repository, so only its collaborators can open
them.
